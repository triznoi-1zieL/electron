## Para rodar

Há um script que compila o arquivo principal e executa o binário gerado, tudo numa tacada:

```
./run.sh
```

Se preferir fazer na mão, é só chamar o compilador apontando para o fonte e depois executar o resultado.

## Limpeza

Outro script apaga os arquivos que o compilador deixou para trás:

```
./clean.sh
```

## Vídeo

Há uma gravação com o jogo rodando no terminal.
